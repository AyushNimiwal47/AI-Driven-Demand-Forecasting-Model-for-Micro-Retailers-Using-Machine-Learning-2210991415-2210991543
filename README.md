## Project Description
An AI-driven demand forecasting framework for micro-retailers (kirana stores) that uses machine learning to predict short-term product demand. The system compares ARIMA, Random Forest, and LSTM models using 18 months of UPI/digital billing data from 5 kirana stores covering 312 SKUs. The proposed LSTM model reduces forecasting errors by 18–25% over ARIMA and performs especially well during festival-driven demand spikes such as Diwali and Holi.

## Key Highlights
- Models compared: ARIMA, Random Forest, LSTM
- Dataset: 18 months, 5 stores, 312 SKUs, ~1.2 million transactions
- Best model: LSTM with MAE 3.21, RMSE 4.87, MAPE 11.4%
- Cold-start handled using category-level proxies and transfer learning
